# Getting Support for NEXUS

Thank you for using NEXUS! We are committed to supporting our community of users, self-hosters, and contributors.

## Where to Get Help

- **Documentation**: Browse our comprehensive guides in the [`docs/`](./docs) folder, including:
  - [Architecture Guide](./docs/ARCHITECTURE.md)
  - [Self-Hosting & Deployment Guide](./docs/DEPLOYMENT_GUIDE.md)
  - [API Reference](./docs/API.md)
  - [System Audit Report](./docs/SYSTEM_AUDIT_REPORT.md)
- **GitHub Discussions**: For general questions, feature requests, or architecture ideas, join [GitHub Discussions](https://github.com/nexus-org/nexus/discussions).
- **Bug Reports**: If you discover a bug, search existing issues first and then submit an issue using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
- **Security Vulnerabilities**: For security concerns, please refer to our [Security Policy](./SECURITY.md) and report privately to `security@nexus.io`.
